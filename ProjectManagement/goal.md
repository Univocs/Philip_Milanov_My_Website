# Productdoel

Maak een publiek portfolio waarmee een bezoeker snel kan begrijpen wie Philip is, voorbeelden kan bekijken van zijn werk rond animatie, rigging en development, en contact met hem kan opnemen.

De eerste release is geslaagd wanneer een bezoeker:

1. De website kan openen op een smartphone of desktop.

2. Vanaf het eerste scherm begrijpt wie Philip is en wat hij doet.

3. Echte projecten, hoogtepunten uit zijn carrière en vaardigheden kan bekijken.

4. Een projectlink kan volgen of bijhorende media kan afspelen.

5. Een contactbericht kan versturen en duidelijke bevestiging ontvangt.

## Scopebeslissingen

* Behandel release 1 als het single-page portfolio dat in de root-README wordt beschreven. Links in de header scrollen naar secties, aparte publieke routes zijn voorlopig niet nodig.

* Bouw telkens één kleine feature volledig end-to-end voordat je aan de volgende begint: API-response, frontendstatussen, styling en tests.

* Gebruik initieel gesede content in het geheugen terwijl de publieke website vorm krijgt. Voeg pas een database toe wanneer persistentie daadwerkelijk nodig is.

* Houd accountbeheer, admin-CRUD, het geanimeerde personage/de chatassistent en uitgebreide carrouseleffecten buiten de eerste release.

* Gebruik zo vroeg mogelijk echte portfolioteksten en media. Placeholder-kaarten zijn onvoldoende om het ontwerp te valideren.
