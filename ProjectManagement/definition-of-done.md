# Definition of Done

Een story is klaar wanneer:

* Alle acceptance criteria slagen.

* Relevante geautomatiseerde tests zijn toegevoegd of bijgewerkt.

* `dotnet test`, `npm run build` en `npm run lint` groen zijn waar van toepassing.

* Loading-, empty-, error- en success-states zijn bekeken.

* De feature werkt met toetsenbordnavigatie en op zowel telefoon- als desktopbreedtes.

* Er verschijnen geen onverwachte fouten in browser- of serverlogs.

* Documentatie die door de story wordt beïnvloed actueel is.

* Het voltooide gedrag werd gedemonstreerd vanaf een clean checkout/setup.
