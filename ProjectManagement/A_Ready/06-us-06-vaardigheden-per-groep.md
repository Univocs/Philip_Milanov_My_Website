# US-06: Vaardigheden per groep bekijken

- **Type:** User story
- **Status:** Ready
- **Volgorde:** 7 van 13
- **Grootte:** S
- **Afhankelijkheden:** US-03 als eerste walking skeleton

## Story

Als bezoeker wil ik vaardigheden gegroepeerd per type bekijken zodat ik Philips capaciteiten snel kan overlopen.

## Acceptance criteria

- De API retourneert geseede skillgroepen en skills volgens `DisplayOrder`.
- De UI toont groepen zoals Tools, Software, Frameworks en Languages.
- Elke skill heeft een naam; een optionele beschrijving wordt alleen weergegeven wanneer die aanwezig is.
- Loading-, empty- en failure-states worden afgehandeld.
- De volgorde en mapping worden afgedekt door een API-integratietest.
